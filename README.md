# NovaFantasyFootball
Nova Fantasy Football is a personal, non-commercial desktop application being developed for analysis of a single Yahoo Fantasy Football league.

The application uses the Yahoo Fantasy Sports API on a read-only basis to retrieve league settings and scoring rules, roster and lineup information, available players, player information, standings, matchups, and transactions.

Intended use: Personal, single-user fantasy football analysis and weekly roster decision support.

Access: Read-only. The application does not make roster changes, add or drop players, submit trades, or perform other write operations.

Distribution: This is a personal development project and is not offered or sold commercially.
